# 宿主适配原型

灵伴系统可以独立运行，也可以被聊天机器人、定时器、个人助理或其他宿主系统唤醒。

## 适配思想

宿主负责三件事：

- 收到主人的消息。
- 把消息交给灵伴主循环。
- 把灵伴生成的文本、面板或轻声铃送回给主人。

灵伴自己负责：

- 情绪变化。
- 羁绊推进。
- 灵息与沉眠判断。
- 命运骰结算。
- 记忆写入。
- 高风险动作面板确认。

## 当前边界

当前公开版只提供安全原型：

- 普通说话可以直接回复。
- 探险请求会先生成面板，不会立刻执行危险行动。
- 主动轻声铃只产生低压力陪伴消息。
- 复活、进化、工具学习等动作应由宿主另行接入确认面板。

## 示例工作目录

请把下面路径换成你自己的项目路径：

```bash
/path/to/soulpet
```

## 示例命令

```bash
npm run demo -- say 阿墨真棒，主人夸夸你
npm run demo -- tick quiet_presence
npm run demo -- adventure crescent_courtyard
```

## 重要原则

> 宿主递信，灵伴回应；代码守命，主人定夺。

也就是说，宿主不应该让灵伴直接越权执行危险动作；灵伴也不应该绕过主人的确认面板。
