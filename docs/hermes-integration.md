# 宿主集成方案

这份文档说明如何把灵伴系统接入任意宿主。这里的「宿主」可以是个人助理、聊天网关、定时任务系统，或你自己的自动化框架。

## 一、普通消息

宿主收到主人文字后，可以调用：

```bash
npm run demo -- say 这里写主人说的话
```

灵伴会根据话语更新情绪、羁绊和记忆，并返回一段中文陪伴回复。

## 二、低风险轻声铃

宿主可以定时调用：

```bash
npm run demo -- cron-tick
```

如果还没到合适时间，命令会保持沉默；如果可以轻声出现，会输出一段温柔陪伴消息。

## 三、探险与面板

探险相关消息不应该直接执行危险结算。推荐流程是：

- 主人提出探险。
- 灵伴生成面板，展示风险、灵息、奖励和选择。
- 主人选择后，宿主再把选择交给灵伴处理。

这样可以避免灵伴擅自进入高危剧情。

## 四、记忆核

公开版默认把演示记忆写在本机用户目录。若你要长期使用，建议把记忆核放入私有仓库或加密目录，不要上传到公开仓库。

## 五、安全边界

- 不自动安装工具。
- 不自动修改宿主项目。
- 不自动删除记忆。
- 不自动对外发消息。
- 高风险动作必须先让主人确认。
- 凭证只放在宿主安全配置中，不写入灵伴源码。

## 六、集成口诀

> 轻声可自来，涉险先叩门；记忆入私库，命运由代码。
