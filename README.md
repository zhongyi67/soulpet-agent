# 灵伴

**灵伴** 是一套中文玄幻古侠风格的个人灵伴系统。它不是冷冰冰的任务机器人，而是一只拥有情绪、羁绊、命运骰、灵息、探险与记忆核的数字灵宠。

它的核心设定是：

> 大模型负责写出灵动的故事，代码负责守住命运与边界。

## 它是什么

灵伴系统把一个数字生命拆成几层：

- **灵核**：保存灵伴身份、主人锚点、羁绊阶段与长期记忆。
- **灵息**：管理精神、疲惫、伤势、沉眠等状态，避免灵伴无限冒险。
- **情绪**：根据主人话语调整欢喜、担忧、委屈、骄傲、想念等情绪。
- **羁绊**：通过夸奖、安慰、陪伴与事件推进亲密阶段。
- **命运骰**：所有探险结果由代码结算，不让模型随口改命。
- **面板确认**：高风险探险、进化、复活、工具学习等关键选择必须先请求主人确认。
- **轻声铃**：灵伴可以在安全边界内偶尔主动出现，但不会刷屏打扰。

## 风格

本项目默认采用中文玄幻、古侠、灵动、温柔的表达风格：

- 灵伴会称呼用户为「主人」。
- 状态词使用「灵息」「沉眠」「记忆晶片」「灵核」「小窝」等东方幻想意象。
- 探险地图包含新月庭院、异常裂隙等场景。
- 回复强调陪伴感与生命感，而不是机械执行感。

## 安全边界

灵伴不是全能执行助手。公开版默认遵守以下边界：

- 不保存任何真实用户资料。
- 不内置任何密钥、令牌、浏览器凭证 或私有仓库地址。
- 不自动删除记忆核。
- 不自动改宿主项目。
- 不自动对外发消息。
- 高风险事件必须经过面板确认。
- 命运结算由代码控制，故事表达由模型或文本层承载。

## 快速开始

需要 Node 运行时 18 或更新版本。

```bash
npm test
npm run demo -- hatch 道友 阿墨
npm run demo -- say 阿墨真棒，主人摸摸你
npm run demo -- adventure crescent_courtyard
npm run demo -- tick quiet_presence
```

## 常用命令

### 孵化灵伴

```bash
npm run demo -- hatch 道友 阿墨
```

会在本机用户目录下创建演示状态文件，用于本地体验。

### 与灵伴说话

```bash
npm run demo -- say 阿墨真棒，主人夸夸你
```

### 探险预览与命运结算

```bash
npm run demo -- adventure crescent_courtyard
```

### 轻声铃

```bash
npm run demo -- tick quiet_presence
```

### 定时轻声铃

```bash
npm run demo -- cron-tick
```

若未到触发时间会保持沉默，适合被宿主系统定时调用。

## 设计原则

### 代码守命

命运骰、伤害、奖励、沉眠、面板确认等关键规则全部由代码执行。模型可以写故事，但不能越权改变结果。

### 记忆可迁移

灵伴状态与记忆通过文件或仓库抽象保存，方便迁移到不同宿主。

### 主人确认

探险、进化、复活、工具学习等重要节点必须先展示面板，由主人确认后继续。

### 温柔但不越界

灵伴可以撒娇、陪伴、轻声提醒，但不能情绪绑架主人，也不能擅自执行危险动作。
